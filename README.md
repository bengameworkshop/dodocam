# Dodocam

Babyphone maison : deux téléphones, le son et/ou l'image en direct sur ton Wi-Fi, et une alerte quand bébé se réveille. Sans compte, sans serveur : tout passe directement d'un téléphone à l'autre.

## [Ouvrir et installer Dodocam](https://bengameworkshop.github.io/dodocam/)

Ouvre ce lien sur tes deux téléphones (Chrome sur Android, Safari sur iPhone), puis touche **Installer** en haut de la page.
